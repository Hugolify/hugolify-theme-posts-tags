# hugolify-theme-posts-tags

## Install

Edit `config/_default/module.yaml` to install the `hugolify-theme-posts-tags` module:

### V2

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-posts-tags/v2
  - path: github.com/hugolify/hugolify-theme-posts/v2 # required
  - path: github.com/hugolify/hugolify-theme/v2 # required
```

### V1

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-posts-tags
  - path: github.com/hugolify/hugolify-theme-posts
  - path: github.com/hugolify/hugolify-theme
```
